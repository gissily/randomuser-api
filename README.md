# randomuser-api
java api client for randomuser.me

## maven
```xml
    <dependencyManagement>
        <dependencies>
            <dependency>
                <groupId>xyz.opcal.tools</groupId>
                <artifactId>randomuser-api-bom</artifactId>
                <version>${randomuser-api.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
        </dependencies>
    </dependencyManagement>
```
